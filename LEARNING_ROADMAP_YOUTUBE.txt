TIMESTAMPER / LYRIC-SYNC LEARNING ROADMAP
==========================================

Purpose
-------
This is a beginner-first map of the concepts used by the TimeStamper project.
It is ordered from essential foundations to optional advanced subjects. You do
not need to reproduce the code while watching. Focus on understanding the
inputs, outputs, and reason each stage exists.

How the view ranking works
--------------------------
View counts below are approximate snapshots checked on 2026-08-27 from current
YouTube/search results. They change over time. Within a topic, higher-view
videos are generally listed first when the view count was available. For some
niche subjects YouTube did not expose a reliable count; those are marked
"view count not exposed" and were selected for clarity, channel quality, and
direct relevance instead of pretending a number was known.

Recommended route
-----------------
P0 = watch first (the minimum useful foundation)
P1 = watch after P0 (understand our actual algorithms and architecture)
P2 = optional (useful depth, not required to follow current development)

Do not try to finish every link before understanding the project. Watch one
video, then open the mapped project files and explain the input/output in your
own words.

14. Spectral flux and onset intuition
    Video: Spectral flux audio feature (search results)
    Views: view count not exposed

    Video: Mel Frequency Cepstral Coefficients (MFCC) Explained
    Views: view count not exposed by the YouTube page
    https://www.youtube.com/watch?v=SJo7vPgRlBQ
    Learn: window -> spectrum -> Mel filter bank -> logarithm -> cepstral

    src/template-aligner.js.

16. Pitch and autocorrelation
    Video: Pitch Detection of Speech Signal Using Autocorrelation - MATLAB Helper

    https://www.youtube.com/watch?v=LAhXjO7SAVw

17. Correlation intuition
    Video: Correlation Explained: Basics, Definition, Function, Types & Importance
    Views: view count not exposed
    https://www.youtube.com/watch?v=FKaCoiTwAsE

ONE-SENTENCE SUMMARY
--------------------
The app does not “read lyrics from sound” magically: it decodes local audio,
turns sound into explainable time-series features, proposes monotonic line
boundaries using replaceable algorithms, lets a person correct them, and
exports the verified timeline as LRC. The learning path above follows exactly
that data flow.
